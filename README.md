## 🧠 The Vision

> *"Every NPC in every game runs a script. I want to build the ones that don't."*

I'm **Utkarsh Verma** — a 2nd-year CSE student at **IILM University, Greater Noida**, on a path to become a **Game AI Engineer**. Not a game dev. Not a web dev. A specialist in giving virtual entities their own cognitive architecture — perception, memory, decision-making, emotion, and goal-driven behavior.

Think GTA 6's pedestrians that remember you. Think NPCs that adapt their playstyle mid-game. Think enemies that aren't reading from a behavior tree someone hardcoded in 2019.
